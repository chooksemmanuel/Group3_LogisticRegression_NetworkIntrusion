# 🛡️ Group 3 — Logistic Regression: Network Intrusion Detection

## 📖 Overview
This workshop replaces the original pass/fail use case with a **Network Intrusion Detection** scenario. Using **Logistic Regression**, we classify network connections as:
* **Normal (0)**
* **Attack (1)** Based on the number of failed login attempts and other connection attributes.

## 🧠 Concepts Covered
* **Linear Regression Recap:** MSE, $R^2$
* **Model Evolution:** Transitioning from Linear to Logistic Regression
* **The Sigmoid Function:** Mapping values to probabilities
* **Statistical Classification:** Decision boundaries
* **Cost Function:** Log-Loss / Cross-Entropy Loss

---

## 📊 Dataset Context
Inspired by the **NSL-KDD** network traffic dataset. The features represent connection-level attributes specifically engineered to detect and distinguish malicious activity from regular traffic.
